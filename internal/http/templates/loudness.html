说明

  • 复用服务端内置 ffmpeg 的 ebur128=peak=true 滤镜，单进程锁定单线程，默认并发 clamp(CPU/2, 1, 2)（可通过 MUSIC_SERVER_LOUDNESS_WORKERS 设为 1-4）。
  • 优先测量已收藏与近期播放曲目所在专辑，其余曲库按专辑聚类顺序测量；曲库扫描或实时转码进行中会自动让路。
  • 测量结果按文件大小与修改时间指纹永久缓存，后续只增量测量新入库或变更的文件。
  • API 只下发原始物理量（loudnessLufs、truePeakDb、albumLoudnessLufs 等），具体目标响度与限幅策略由各客户端自行控制。
