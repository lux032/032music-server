尚未部署

需要先启动分析服务

声学分析由独立容器 music-analyzer 完成（源码在仓库 analyzer/）。在 compose.yaml 所在目录：

  1. 在 .env 中设置 MUSIC_SERVER_ANALYZER_URL=http://music-analyzer:8000，并为 MUSIC_SERVER_ANALYZER_TOKEN 设置一个随机值（两个容器共用）。
  2. 执行 docker compose --profile analysis up -d --build，首次启动会下载约 53MB 模型。
  3. 回到本页，打开“声学分析”开关即开始首次全量分析。

说明

  • 每首歌取 3 段 30 秒分析，保存 400 类风格、56 类情绪/主题、40 类乐器、人声/可舞性等指标，以及 1280 维声学向量（每首约 3.8KB，1.7 万首约 65MB）。
  • 唤醒度/效价：先用完整模式分析约 300 首作为校准样本，在本服务器拟合回归模型，其余曲目据此计算，省去约 60% 的分析时间。
  • 使用 MTG Essentia 预训练模型，许可为 CC BY-NC-SA 4.0，仅限非商业用途；模型由分析服务在首次启动时下载。
