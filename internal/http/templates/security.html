两步验证（2FA）

{{if .TOTPEnabled}}已启用{{else}}未启用{{end}}

登录管理面板时，除密码外还需输入身份验证器（Google Authenticator、1Password、Microsoft Authenticator 等）生成的 6 位验证码。只影响管理面板登录，不影响 API Token 与媒体 Token。启用或停用后其他登录会话会全部退出。

{{if .TOTPEnabled}}

丢失手机时，可临时设置 MUSIC_SERVER_RESET_CREDENTIALS=password 并重启服务：会关闭两步验证，并把用户名与密码恢复为环境变量。

停用两步验证…
停用后登录只需密码。
